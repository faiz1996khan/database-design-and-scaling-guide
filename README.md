# Database Design & Scaling Guide

A practical PostgreSQL lab covering database design and scaling concepts using Docker.

## Topics

* Indexing
* Partitioning
* Sharding
* Replication
* Multi-primary replication

Each section contains hands-on Docker examples, SQL queries, experiments, and explanations of the trade-offs involved.

## Stack

* PostgreSQL 17
* Docker & Docker Compose
* SQL
* Node.js / Javascript where application-level examples are needed

## Goal

Understand how database systems scale, remain available, and handle traffic through practical experiments.
